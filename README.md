# Mihir Balsara — retro portfolio

Open `index.html` in a browser. No installation or build needed.

White, compact, centered-width early-2000s Apple-inspired landing page with bundled Apple Garamond Light, softly glossy silver pill buttons beneath the name, a fine-rule footer, and no stripes or paint animation. The clock sits at the bottom right on laptop screens and below the copyright on mobile. Scrolling and scroll bounce are disabled; desktop and mobile layouts fit the viewport.

The live clock uses the visitor's device timezone, handles daylight saving time automatically, and updates every second. Format: `October 6, 2026 1:23 PM PDT` for a visitor in Pacific time.

The Resume button opens `resume.pdf`, the Oracle version of the résumé. LinkedIn and GitHub link directly to your profiles.

Original reference: https://web.archive.org/web/20010601020717/http://www.apple.com/ (including its glossy Search button and compact Geneva footer).

Apple Garamond Light is bundled in `fonts/AppleGaramond-Light.ttf`.
